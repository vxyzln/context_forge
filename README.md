# Context Forge (v0.5.5)

A deterministic, local-first engine for extracting minimal necessary context from software projects for AI agents.

## Current Status (v0.5.5)
- Implemented: Project ingestion, Python parsing, Graph construction (definitions and imports), SQLite persistence, Deterministic relevance ranking & budget compression.
- Future Goals: Additional language support, Git intelligence, Local LLM integration, Web UI.
